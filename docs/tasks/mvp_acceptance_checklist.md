# NeonType MVP Acceptance Checklist

仕様の正は [docs/specs/mvp.md](../specs/mvp.md)。見た目の基準は `mockups/a/start.html` と `mockups/a/play.html`。

## 画面・遷移

- [ ] スタート画面に説明、4つのモードカード、4部門ランキングがある
- [ ] モード選択でプレイ画面へ進む
- [ ] 制限時間 0 でリザルトへ進む
- [ ] 終了ボタンは確認後にリザルトへ進む
- [ ] ミス時は 3 秒演出のあと、同じ文を先頭からやり直す
- [ ] リザルトからスタートへ戻れる

## 入力・スコア

- [ ] 長文は固定ローマ字の 1 キー一致。複数表記は使わない
- [ ] 日本語 1 文字完了で加点。ローマ字途中だけでは加点しない
- [ ] ミスで減点・コンボ 0・Perfect 対象外
- [ ] コンボ倍率は 0=1.0、5以上=1.5。減点に倍率なし
- [ ] 合計スコアは四捨五入の整数で、下限 0
- [ ] プレイ中のキー入力は API に送らない。終了時に 1 回だけ保存

## ランキング

- [ ] 部門は長文 3/5 分、コード 3/5 分
- [ ] 上位 10、同点は先登録が上
- [ ] 11 位以下または未登録は「ランク無し」
- [ ] 名前 1〜12 文字。空は「ゲスト」。二重登録しない

## データ・運用

- [ ] 匿名 ID は localStorage。ログインなし。個人情報なし
- [ ] D1 は migration 管理。ローカルと本番を分離
- [ ] `just check` = `vp check` + `vp test` + `vp build` が通る
- [ ] 長文約 30、コード約 30（HTML/CSS/JS/Java/C#/C++）

## 演出（案A）

- [ ] ネオン配色、仮想キーボード発光
- [ ] ミス赤転 + 3 秒リング
- [ ] コンボ炎、Perfect 虹色、残り 10 秒警告、スコアポップ
